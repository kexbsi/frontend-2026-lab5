## Завдання 1 — форма з перевіркою регулярними виразами

Рядок таблиці 1: 122 mod 15 = **2** → поля 1, 3, 4, 5, 6 таблиці 2:

| Поле | Формат | Регулярний вираз |
|------|--------|------------------|
| ПІБ | ТТТТТТ Т.Т. | `^[А-ЯҐЄІЇ][а-яґєії'’]+(?:-[А-ЯҐЄІЇ][а-яґєії'’]+)? [А-ЯҐЄІЇ]\.[А-ЯҐЄІЇ]\.$` |
| Група | ТТ-ЧЧ | `^[А-ЯҐЄІЇ]{2}-\d{2}$` |
| Телефон | (ЧЧЧ)-ЧЧЧ-ЧЧ-ЧЧ | `^\(\d{3}\)-\d{3}-\d{2}-\d{2}$` |
| ID-card | ТТ №ЧЧЧЧЧЧ | `^[А-ЯҐЄІЇ]{2} №\d{6}$` |
| Факультет | ТТТТ | `^[А-ЯҐЄІЇ]{4}$` |

Якщо все правильно — введені дані показуються в окремому вікні (`window.open`; якщо браузер блокує
спливні вікна — у модальному `<dialog>`). Якщо є помилки — рядки з помилками підсвічуються червоним.

## Завдання 2 — таблиця 6×6

122 mod 10 = **2**: клітинка № 2. Наведення (`mouseover`) — випадковий колір, клік (`click`) — колір
з палітри (`<input type="color">`), подвійний клік (`dblclick`) — колір з палітри для всього стовпця.
